Java: a secured Spring Boot endpoint 
@RestController
@RequestMapping("/api/cards")
public class CardController {
  private final CardService service;

  public CardController(CardService service) {
    this.service = service;
  }

  @GetMapping("/{id}/balance")
  public ResponseEntity<BalanceDto> balance(
      @PathVariable Long id, Principal user) {
    return ResponseEntity.ok(
        service.balanceFor(id, user.getName()));
  }
}

Constructor injection, a thin controller and the logged‑in user passed to the service, so people can only read their own data.
